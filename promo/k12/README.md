# FloatTranslate K12 Promo Video

这是 FloatTranslate 面向 K12 学习场景的横屏宣传视频源码。

## 内容

- `index.html`：视频画面、动效、字幕和场景脚本
- `hyperframes.json`：HyperFrames 入口配置
- `design.md`：设计方向说明
- `package.json`：本地渲染脚本

## 本地预览

```bash
npx hyperframes preview
```

## 本地渲染

```bash
npx hyperframes render
```

## 注意

当前 GitHub 连接器已上传文本源码。音频素材和最终导出的 `.mp4` 属于二进制文件，建议后续放到 GitHub Releases、官网下载目录或云盘，再在这里补链接。
